A simple web application that mimics the functionality of ChatGPT, built using React for the frontend and Express.js for the backend.
This app integrates with OpenAI’s GPT-3.5-turbo Chat Completions API to maintain continuous, coherent conversation threads between the user and the chatbot.

Tech Stack
1. Frontend: React, Axios
2. Backend: Express.js, Node.js, Axios, Dotenv
3. AI Model: OpenAI GPT-3.5-turbo
